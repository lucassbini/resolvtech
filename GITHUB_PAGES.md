# Resolv Tech // Visitas Operacionais — GitHub Pages

Esta versão é para abrir diretamente pelo GitHub Pages, sem Render, Docker ou banco externo.

1. Envie o conteúdo desta pasta para um repositório GitHub.
2. Vá em Settings → Pages.
3. Em Build and deployment, selecione Deploy from a branch.
4. Branch: main / root.
5. Salve.
6. O GitHub fornecerá um link HTTPS para o Dashboard.

Observação: GitHub Pages é hospedagem de arquivos estáticos. Dados que dependam de um servidor/banco PostgreSQL não serão persistentes entre usuários nesta modalidade.
